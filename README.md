# Eyad Moneim Portfolio

A creative web portfolio for Eyad Moneim, featuring smooth scroll animations, Three.js 3D elements, and responsive design. This project showcases innovative projects, robust architectures, creative campaigns, and UI/UX designs.

## Features

- **Smooth Scrolling:** Powered by GSAP ScrollTrigger for seamless navigation and story-telling.
- **3D Elements:** Interactive Three.js elements using React Three Fiber.
- **Rich Animations:** Framer Motion variants and GSAP timelines.
- **Component Architecture:** Modular React components for maintainability.

## Tech Stack

- **React 18**
- **Vite**
- **Framer Motion**
- **GSAP & ScrollTrigger**
- **Three.js & React Three Fiber**

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
